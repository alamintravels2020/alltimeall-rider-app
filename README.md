# alltimeall Rider Smart Android Application

অ্যান্ড্রয়েড অ্যাপটি **alltimeall.com/rider** পোর্টালের জন্য সম্পূর্ণ রেডি করা হয়েছে।

## 🚀 বৈশিষ্ট্যসমূহ (Rider App Features)

1. **রাইডার পোর্টাল ইন্টিগ্রেশন**: সরাসরি `https://alltimeall.com/rider` ইউআরএল লোড করবে।
2. **জিটিএস ও লোকেশন ট্র্যাকিং**: ডেলিভারি রুট ও ম্যাপ নেভিগেশনের জন্য GPS/Location সাপোর্ট।
3. **ক্যামেরা ও ডেলিভারি ফাইল আপলোড**: রাইডারদের পিকআপ/ডেলিভারি প্রুফ ছবি ও ডকুমেন্ট আপলোড করার সুবিধা।
4. **অরিজিনাল ব্র্য্যান্ডিং ও আইকন**: alltimeall ব্র্যাণ্ড অরেঞ্জ থিম (`#F97316`) ও `ALLTIMEALL LOGO 512.png` লোগো।
5. **Pull-to-Refresh & Progress Indicator**: লাইভ অর্ডার পেজ দ্রুত রিফ্রেশ করার সুবিধা।
6. **অফলাইন মোড ও রিট্রাই বাটন**: নেটওয়ার্ক চলে গেলে রাইডারকে অফলাইন ডায়ালগ দেখাবে এবং সংযোগ ফিরলে পুনরায় চেষ্টা করার সুবিধা।
7. **ম্যাপস ও ফোন কল ইনটেন্ট**: গুগল ম্যাপস চ্যাট, হোয়াটসঅ্যাপ চ্যাট ও ফোন কলের সুবিধা।

---

## 🛠️ কিভাবে APK বিল্ড করবেন (How to Build APK)

1. **Android Studio** চালু করুন।
2. `Open` এ ক্লিক করে `d:\alltimeall apps\alltimeall Rider` ফোল্ডারটি নির্বাচন করুন।
3. গ্রেডেল সিঙ্ক শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
4. মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)** এ ক্লিক করুন।
